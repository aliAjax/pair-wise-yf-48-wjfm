# pair-wise-yf-48 建筑设计竞赛匿名评审

源提示词摘要：主办方设置评分维度、权重和提交规则，评委在匿名状态下独立查看方案、打分、填写意见、声明利益冲突和保存草稿；系统提供提交进度、异常分处理、结果锁定与并列排名规则。

## 技术栈

Vue3、TypeScript、Vite、Naive UI、Pinia、Vue Router、Axios、VueUse、VeeValidate、Zod、Vue I18n。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发端口：62013

## 本地存档

评分草稿、提交流水与锁定结果写入 `localStorage`（键 `pair-wise-yf-48/review`），存档带版本号（当前 v2），无版本字段的旧数据按 v1 兼容迁移，原有草稿与锁定结果照常读出。

- 写入失败时按退避节奏自动重试；仍失败则数据暂留内存并提示“未存档”，之后继续自动重试。
- 容量不足时分批腾退最旧的未提交草稿与流水事件后重试；已提交评分、锁定结果及锁定事件不参与腾退。
- 多个窗口同时保存时以三路合并保留双方内容；同一项撞车时后保存者看到冲突提示，本窗口内容作为草稿保留，对方版本留档，可选用对方版本或保留自己的草稿。
